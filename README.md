# HireAlpha

Landing page for **HireAlpha** — hire Friend, Coworker, or Cofounder in iMessage. Three agents, three numbers, connectors to the apps you already use.

## Stack

- Vite + React + TypeScript
- Framer Motion
- Simple Icons

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Notes

- Waitlist emails are stored in `localStorage` on the client for now.
- Do not commit `.env` files. Copy `.env.example` if one is added later.
